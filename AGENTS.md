# Edge AI Challenge 2026 - Hardware & Competition Invariants

## 1. Microcontroller Target Constraints (ESP32-S3 N16R8)
- Target Chip: ESP32-S3 (Xtensa dual-core LX7 @ 240MHz, 512KB SRAM, 8MB PSRAM, 16MB Flash).
- Model Parameter Limit: Strictly < 200,000 parameters per model (Hard limit).
- Model Flash Budget: <= 1.5 MB total across all deployed models.
- Quantization Standard: Full Integer INT8 quantization (`inference_input_type: INT8`, `inference_output_type: INT8`).
- Input Resolution: <= 160x160 pixels (e.g. 128x128, 144x144, 160x160).
- Runtime Compatibility: TensorFlow Lite Micro (TFLM). Zero unsupported operators (avoid custom CUDA ops, dilated convolutions with non-unit strides, or large multi-head attention).

## 2. Zero Unconstrained Submissions
- Never submit predictions generated by models exceeding the ESP32-S3 budget.
- All submissions must originate from reproducible INT8 TFLite weights.
- Note: Organizers physically flash models onto ESP32-S3 boards for the official evaluation; unconstrained models (90+ LB scores) will be disqualified.

## 3. Quantization Protocol (PTQ vs QAT)
- For Keras 3 models, use Post-Training Quantization (PTQ) with a representative dataset of 100+ training images.
- Do NOT use `tfmot.quantization.keras.quantize_model` with Keras 3 weights, as partial layer matching silently uninitializes up to 30% of network layers (causing catastrophic mAP drops from 60% to 31%).

## 4. Submission Gating & Density Sweet Spot
- Before uploading any submission CSV to Kaggle:
  1. Validate against `sample_submission.csv` (exact column headers, row IDs, formatting).
  2. Inspect total detection count ($N$). For the 60-image test set, ensure $2,600 <= N <= 2,800$ (43–47 boxes/img). Reject submissions outside this range unless calibrated on local validation.
  3. Precomputed Intent predictions (`submissions/intent_preds.csv`) must be strictly merged (Score 30.00/30.00).

## 5. Kaggle T4x2 Remote Workflow
- For datasets > 500 images, execute training remotely via `warmup/kaggle_runner/run_remote_train.py` on dual T4 GPUs.
- Pull weights to `warmup/weights/kaggle_t4/` and run local validation (`data/val_split.txt`) before submitting.
